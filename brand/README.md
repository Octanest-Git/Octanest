# Brand

## Mark

![Oxidean mark](./oxidean-mark.png)

Primary logo for now: `oxidean-mark.png` (1024×1024 PNG), rendered from
`oxidean-mark.svg` (vector source of truth — `rsvg-convert -w 1024 -h 1024`).

- Faceted octahedron "oxide crystal" — sharp angular vectors
- Oxide-orange facet ramp (`#ffab74` → `#8f3c04`), specular sliver
- Transparent ground; prefer on charcoal/dark backgrounds

## Palette

- Charcoal `#121212` — dark canvas / icon ground
- Burnt oxide `#d75f00` — brand accent (mark, charts)
- Functional text-role variant `#bf4b0a` (light theme primary, AA ≥4.5:1)

## Usage

Use the PNG for README, favicon source, and UI chrome. Raster app icons are
generated by `scripts/gen-icons.sh` (squircle mask + charcoal flatten).
