# Support

- **Questions and community:** [GitHub Discussions](https://github.com/oxidean/oxidean/discussions) — usage questions, ideas, show-and-tell. Please don't open issues for general questions.
- **Docs:** [`docs/`](docs/) — getting started, deployment, configuration, development
- **Bugs and feature requests:** [open an issue](https://github.com/oxidean/oxidean/issues/new/choose) using the issue forms
- **Product:** Oxidean Cloud at [app.oxidean.dev](https://app.oxidean.dev); overview at [oxidean.dev](https://oxidean.dev)
- **Security:** see [SECURITY.md](SECURITY.md) — don't file public issues for vulnerabilities
