| Property | Value |

## Typography

**Inherited — exactly 4 sizes, 2 weights:**

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Label | 14px | 400 | 1.4 | Source Sans 3 |
| Body | 16px | 400 | 1.5 | Source Sans 3 |
| Heading | 24px | 600 | 1.2 | Sora |
| Display | 40px | 600 | 1.15 | Sora |

**Weights used:** **400** and **600** only.

**Code surfaces (not a fifth role):** Blob, blame, diff, and commit hunks use **system UI monospace** (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`) at **Label 14px** (dense) or **Body 16px** (blame comfort) weight **400**, line-height **1.45**. Path breadcrumbs and SHA strings use Label + monospace for SHAs only.

**Phase 7 application map:**
- Repo title, `/new` title, empty heroes → **Heading**
- Home empty hero may use **Display** only if viewport is sparse; default **Heading**
- Support, README prose, errors → **Body**
- Nav links, badges, meta, helpers, CTA labels → **Label** (CTA labels weight **600**)
- Markdown headings inside README: map h1→Heading, h2/h3→Body 600 — stay within declared weights

1. **New repository**, **Create repository**, **Save visibility**, **Save default branch**
2. Active Code/Commits/Branches/Tags nav indicator
