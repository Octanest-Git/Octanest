|---------|----------|

## Typography

**Inherited — exactly 4 sizes, 2 weights:**

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Label | 14px | 400 | 1.4 | Source Sans 3 |
| Body | 16px | 400 | 1.5 | Source Sans 3 |
| Heading | 24px | 600 | 1.2 | Sora |
| Display | 40px | 600 | 1.15 | Sora |

**Weights used:** **400** and **600** only.

**Phase 8 application map:**
- Page titles, empty heroes, reveal warning title → **Heading**
- Support, how-to prose, errors → **Body**
- Nav links, badges, meta (last used, IP), helpers, CTA labels → **Label** (CTA labels weight **600**)
- Token plaintext, clone URLs, example commands → monospace at Label **14px** or **13px** weight **400** (not a fifth typography role)

Do **not** use Display on settings forms.
